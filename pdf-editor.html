What can I do with this free PDF editor?

This online PDF editor works like a desktop PDF program inside your browser. Change existing text or replace a word on every page, add new text, sign documents, insert clickable links, create fillable form fields, add images and ready-made stamps, highlight, strike out or underline, draw shapes and arrows, hide information with whiteout, and rotate, reorder, delete or insert pages. Your file stays on your device.

How do I edit a PDF online?

  1. Click Select PDF and choose your file, or drag it onto the box. All pages open in large size, one below the other.
  2. Pick a tool from the toolbar, such as Text, Sign or Whiteout, and click or drag on the page.
  3. Click any item to select it, drag to move it, and use the blue handle to resize. Press Delete to remove it.
  4. Use the buttons above each page to rotate, move or delete it, or insert a blank page.
  5. Click Download PDF to save the edited file.

Is it safe to edit a PDF here?

Yes. Your PDF is opened with PDF.js and saved with pdf-lib, two open-source libraries that run inside your browser. The file is never sent to our server, so it is suitable for bank statements, invoices, GST documents and other private papers. Password-protected PDFs must be unlocked before editing.

Frequently asked questions

1. Is this PDF editor really free?

Yes. All tools are free, with no signup and no watermark.

2. Is my PDF uploaded to a server?

No. The PDF is opened and edited in your browser, and the edited file is created on your device.

3. Can I edit existing text in a PDF?

Yes. Choose Text › Edit existing text and click a line. The old text is covered with white and an editable box with the same words appears on top. Text › Find & replace changes a word on every page at once. The new text uses a standard font, so it may look slightly different from the original.

4. Can I add fillable form fields and links?

Yes. Forms adds text fields, multi-line fields, checkboxes and drop-down lists that can be filled in any PDF reader. Links adds clickable links to a website, an email address or another page.

5. How do I sign a PDF online?

Click Sign, draw your signature or upload a photo of it, place it on the page, resize it with the blue handle and download.

6. Can I type in Hindi or use the ₹ symbol?

Yes. Hindi text and symbols such as ₹ are added as high-resolution images so they display correctly everywhere. Plain English text is added as real, selectable text.

Which technology powers this editor?

The editor saves your file with pdf-lib, a library built to "create and modify PDF documents in any JavaScript environment".

— pdf-lib project documentation
  • PDF.js by Mozilla: displays the PDF pages and reads existing text
  • pdf-lib: writes your changes, links and form fields into the PDF
  • ISO 32000-2: the international standard for the PDF format
