How to import invoices from Excel into Tally (step by step)

  1. Export your ledger list from Tally. In TallyPrime go to Gateway of Tally → Chart of Accounts → Ledgers, press Ctrl+E (Export), choose Excel (Spreadsheet) as the format and press Send. In Tally ERP 9 the export key is Alt+E. You can also use Display More Reports → List of Accounts.
  2. Load that file in Step 1 above. The tool now knows the exact spelling of every ledger in your company.
  3. Check your GST ledgers. Ledger names in Step 2 must exist in Tally exactly as typed, for example "Sales @18%", "Output CGST", "Output SGST", "Output IGST" and "Round Off". Use {rate} in the sales or purchase ledger name if you keep one ledger per rate. Create any missing ledger in Tally first (Create → Ledger), under Sales Accounts, Purchase Accounts or Duties & Taxes (type GST) as needed.
  4. Prepare the Excel using the sample format: one row per invoice per GST rate. An invoice with 5% and 18% items has two rows with the same invoice number.
  5. Upload, check the column mapping and press Check invoices. Fix red rows, confirm party name matches, and press Re-check.
  6. Download the Tally XML.
  7. Import in Tally. In TallyPrime: Gateway of Tally → Import (Alt+O) → Transactions, give the XML file path and import. In Tally ERP 9: Gateway of Tally → Import of Data → Vouchers.
  8. Verify. Open the Day Book for the period and match the totals with this tool. Then check GSTR-1 or GSTR-3B in Tally.
Tip: always take a backup, or try the file on a test company first.

Shortcut for matching party names

The biggest reason Tally imports fail is a small spelling difference, like "Sharma Traders" in Excel and "SHARMA TRADERS PVT LTD" in Tally. After you load the ledger list, the tool suggests the closest Tally name for every party. You only need to correct the few that are wrong, and your choices are remembered for next month.

Common Tally import errors and fixes

  • Ledger does not exist: the name in the file is not in Tally. Load your ledger list in Step 1 so the tool catches this before import, or create the ledger.
  • Date out of range: the invoice date is outside the books period of the company. Change the period or check the dates.
  • Educational mode: Tally in educational mode only accepts the 1st, 2nd and 31st of a month.
  • Invoices missing in GSTR-1 in Tally: party ledgers need their GSTIN and state, and the sales and tax ledgers need GST details set in Tally.

FAQ

Does it work with TallyPrime and Tally ERP 9?

Yes. Both accept this XML voucher format.

Is my data uploaded anywhere?

No. The Excel is read and the XML is built inside your browser.

Does it create item-wise inventory invoices?

Not yet. It creates accounting vouchers with ledger-wise GST. Item-wise invoices need stock items set up in Tally.
