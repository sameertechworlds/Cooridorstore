Complete guide: import invoices from Excel to Tally

Step 1: Export your chart of accounts (ledger list) from Tally

This makes sure every party and ledger name in the XML matches Tally exactly. Even one extra space or a different spelling causes the error "Ledger does not exist".

  1. TallyPrime: Gateway of Tally → Display More Reports → List of Accounts. Press Ctrl + E (Export), choose Format: Excel, and press Enter to export.
  2. Tally ERP 9: Gateway of Tally → Display → List of Accounts. Press Alt + E, choose Excel format and export.
  3. Upload that Excel in Step 1 above. The list is remembered on this device for next time.

Shortcut tip: in List of Accounts, press Ctrl + B (or F5 in ERP 9) to switch to Ledgers view so that only ledger names are exported, not groups.

Step 2: Prepare your invoice Excel

Download the sample format above. One row per item or per GST rate. Rows with the same invoice number become one voucher.

Step 3: Match ledger names

Enter the exact names of your item and tax ledgers in Settings, such as "Sales @18%" or "Output CGST". Write {rate} where the rate should appear, so "Sales @{rate}%" becomes "Sales @18%" and "Sales @5%" automatically. Any ledger not found in your Tally list is flagged.

If a ledger is missing, create it in Tally first: Alt + G (Go To) → Create Ledger, or Gateway → Create → Ledger. For tax ledgers, choose group Duties & Taxes, type of duty GST, and the correct tax type.

Step 4: Import the XML into Tally

  1. Take a backup first or test on a copy of the company.
  2. TallyPrime: press Alt + O (Import) → Transactions. Enter the full path of the XML file, for example C:\Users\You\Downloads\tally-import.xml, and press Enter.
  3. Tally ERP 9: Gateway of Tally → Import of Data → Vouchers, enter the file path and press Enter.
  4. Check the import summary for created and errored vouchers.

Duplicate protection: in TallyPrime, set "Behaviour of import if voucher already exists" to Ignore Duplicates so the same invoices are never entered twice.

Common import errors and fixes

Error in TallyFix
Ledger 'X' does not existCreate the ledger or correct the name using the ledger list.
Voucher totals do not matchTurn on Round off and make sure the Round Off ledger exists.
Date is out of rangeThe invoice date is before Books Beginning or outside the current period. Change the period with Alt + F2.
Voucher type does not existMake sure a voucher type named exactly Sales or Purchase exists.

Frequently asked questions

Does this work with TallyPrime and Tally ERP 9?

Yes. The XML follows Tally's standard voucher import format used by both.

Is my data uploaded anywhere?

No. Files are read and the XML is created inside your browser.

Can I import purchase invoices from GSTR-2B?

Yes. Reconcile first using our GSTR-2B Reconciliation tool, then arrange the matched invoices in the sample format and import them as Purchase.
